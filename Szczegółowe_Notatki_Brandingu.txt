Additional fixes 9: WakingUp uses svgs and a "hydration", instead of replacement, SVGs are drawn as vectors. Browsers treat them like shapes, not text, so they don't suffer from font-smoothing glitches. I use standard text, and when a browser animates standard text, it temporarily turns off "Sub-pixel Antialiasing" to save performance. This causes the text to look thin or develop a "white outline/shimmer" during the move. they use starting state css: .bJbLNM {
    opacity: 0; /* Elements start invisible in the CSS file */
    transition: opacity 300ms ease;
}. in the static CSS file. They also use position: absolute; z-index: 11; transform: translateY(10px)... By using position: absolute on animated elements, they pull those elements out of the "flow" of the page. This tells the browser: "This item is on its own layer." When it moves, the browser doesn't have to re-calculate the pixels of the background or the text around it, which eliminates the "ghosting" or "outline" effect.
