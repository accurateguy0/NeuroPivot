Heuristics: follow these guidelines: Nielsen's 10 Usability Heuristics, Shneiderman's 8 Golden Rules, Dieter Rams' 10 Principles of Good Design, Weinschenk & Barker Classification, Arhippainen's User Experience Heuristics, Amélie Boucher's Ergonomic Criteria, ISO 9241 Part 110 Dialogue Principles, Colombo & Pasch's Heuristics, Don Norman's, Principles of Design, Tognazzini's First Principles of Interaction Design, WCAG 2.2 POUR Principles, Laws of UX

Visual Directive:
The Canvas: Enforce a strict 1px solid border on all containers using var(--border-color). No border-radius.
Color Psychology:
Apply Pacific Blue for 'Rest/Science' views (Sleep Flow, Recommended Page).
Apply Grapefruit Pink for 'Action/Stress' views (Habit List, Focus Flow).
The "Waking Up" Transition: In Home.razor, when ActiveView changes, do not swap instantly. Implement a CSS transition where the old view fades out and scales down (0.98) while the new view fades in and scales up (0.98 to 1.0).
Typography Storytelling:
Headers: 'Inter' with -0.05em letter-spacing.
Scientific Quotes: 'Baskerville' or 'Fraunces' (The 70s Soft Serif).
System Metadata: 'Nimbus Mono' (The Student/IT vibe).
Refined Components:
Habit Table: Make it "Dense." Use thin lines and ensure the "Day 01...21" headers are in Mono.
Focus Timer: Create a "Breathing Circle" SVG that expands/contracts based on the FocusFlow state.
Checkboxes: When a habit is ticked, replace the standard checkbox with a Pink "LTP" strike-through animation.
Hydration Guard: Ensure no text shimmers. Use translate3d(0,0,0) and backface-visibility: hidden.
Logic Polish:
Integrate a "Confetti Trigger" in HabitService that JS-calls a confetti burst only when the 6th habit is checked.
Ensure localStorage correctly saves the "Addicted/Concerning/Average" score and changes the "Recommended" quote density accordingly.
Personality: Keep it "Savage but Scientific." The UI should feel like an expensive diagnostic tool used by a genius student. To get that "fluid" feel, you should use CSS Scroll Snapping. This makes the page feel like a controlled presentation rather than a random scroll.  Keep your "Core" (Shadow Grey/Ghost White) for 90% of the UI. Use the colors only for data-heavy accents (the progress bar, the checkmark, the active timer). This creates a "Quiet UI" that only speaks when it’s important.To make it look like a top-tier studio project:
The "Paper" Texture: Add a very subtle "Grain" overlay to your Shadow Grey background. It makes the screen look like expensive paper rather than a flat digital pixel.
View-Transition API (or CSS Equivalent): Since you swap subpages via AppState.ActiveView, the swap is currently instant (which feels cheap). You need a "Cross-Dissolve + Scale" transition.
